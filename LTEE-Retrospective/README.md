# LTEE Retrospective Research Archive

This directory preserves the original WSL research scripts
for LTEE phylogenetic reconstruction, ancestral genome
inference, temporal modeling, and Evo2-related experiments.

## Important methodological limitation

Some retrospective temporal-head datasets were constructed
using ancestral sequences inferred from phylogenetic trees
containing later sampled descendants.

Consequently, these datasets may contain future-descendant
information leakage and must not be interpreted as strictly
prospective forecasting benchmarks.

The original scripts are preserved for reproducibility,
historical comparison, and methodological investigation.

## Research transition

The prospective benchmark was developed to avoid dependence
on full-tree ancestral reconstruction by using observed
clone-specific SNP calls and chronological information
constraints.

The prospective benchmark is not yet certified for
confirmatory evaluation.
