# LTEE Prospective Sequence Forecasting

## Research objective

Predict future sampled-clone nucleotide sequences using
historical genomic observations and evolutionary dynamics.

## Benchmark status

Phase 1.4: SPECIFIED_NOT_CERTIFIED

The real LTEE prospective benchmark has not yet been
certified for confirmatory evaluation.

## Synthetic experiments

- Phase 2A: Shared vs hierarchical CTMC
- Phase 2B: Parameter recovery and shrinkage
- Phase 2C: Held-out rare-event forecasting
- Phase 3A: Sequence-context susceptibility
- Phase 3B: Four-state context-aware CTMC

## Important limitations

Synthetic experiments validate model behavior under controlled
generative assumptions.

They do not establish prospective forecasting performance
on real LTEE genomes.

Earlier retrospective ancestral reconstruction experiments
may contain future-descendant information leakage.
See ../LTEE-Retrospective/README.md.
